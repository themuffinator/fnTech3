# Material rules for Heavy Metal: F.A.K.K.2's audio zones.
#
# F.A.K.K.2's maps carry almost no material surfaceparms (two `metal` and two
# `wood` shaders in the thirty retail maps), so zone materials come from shader
# names, as Alice's do. The compiler's own name tokens cover 42.0% of the retail
# maps' draw surfaces; these rules add F.A.K.K.2's own texture vocabulary --
# its level folders and its wl_/fl_/wa_ prefixes -- and raise that to 87.6%.
# Each pattern was checked against every shader name the retail maps use. The
# only names where a rule and a compiler token disagree are the Water level's
# walls, statues and glass tubes, which its `water` token calls liquid, and the
# church's wood trim, which is both. Weight 1 puts every rule on a par with the
# compiler's tokens: these are naming heuristics, not overrides.
#
# Patterns are case-insensitive substrings of the shader path.
