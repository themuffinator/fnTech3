# Material rules for American McGee's Alice's audio zones.
#
# Alice's maps carry almost no material surfaceparms (eight shader records in
# the thirty-six retail maps), so zone materials come from shader names. The
# compiler's own name tokens cover 54.7% of the retail maps' draw surfaces;
# these rules add Alice's own texture vocabulary and raise that to 76.3%.
# Each pattern was checked against every shader name the retail maps use: none
# matches a name the compiler's own tokens give a different material, except
# bark_water, which is both. Weight 1 puts every rule on a par with those
# tokens: these are naming heuristics, not overrides.
#
# Patterns are case-insensitive substrings of the shader path.
