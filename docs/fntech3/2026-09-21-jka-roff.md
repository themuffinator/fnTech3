# Jedi Academy motion paths: reading ROFF

## Scope

A ROFF file is a recorded path: a list of position and rotation offsets an
object follows a frame at a time, with a note track that fires script
callbacks along the way. Jedi Academy's cameras, lifts and cut-scene props
move on them. This slice adds a bounded reader and the checks that hold it to
Raven's layout.

Nothing is moved along a path here: this is a format boundary. Every motion
path in a legitimate retail installation reads through it.

## The format

The identifier is `ROFF` and two versions are defined
(`codemp/qcommon/RoffSystem.h:33`-`:100`):

| | Version 1 | Version 2 |
| --- | --- | --- |
| Header | 12 bytes: identifier, version, entry count **as a float** | 20 bytes: identifier, version, entry count, frame rate, note count |
| Entry | 24 bytes: position offset, rotation offset | 32 bytes: the same, plus the first note it fires and how many |
| After the entries | nothing | the note track: that many terminated strings |

The float entry count in version 1 is Raven's own note in the source: the
exporter could not write an integer there.

A legitimate 1.01 installation ships 92 motion paths and **all of them are
version 2**, every one at 50 frames a second, the longest 500 entries, and
three of them carrying a note track. Version 1 is therefore read from the
format definition rather than from an observation.

## What the reader guarantees

`code/compat/jka_roff_format.hpp` reads both versions. Beyond the usual bounds:

- a version 1 count that is not a whole, representable number of entries is a
  malformed file, not a path of unusual length;
- a frame rate of zero or less is refused, because a path is played at it;
- an entry's note range must lie inside the track that follows, with `-1`
  meaning the entry fires nothing;
- the note track must be exactly that many terminated strings and must end the
  file: a path with bytes left over, or with a string that never terminates,
  is refused rather than half-read.

## Evidence

| Check | Evidence |
| --- | --- |
| Retail paths | All 92 motion paths in a legitimate 1.01 installation read: version 2, 50 frames a second, up to 500 entries, three with note tracks, none refused (`scripts/probe_jka_assets.py`) |
| Version 2 | A synthetic path reads with its entries, rate, note count and the notes an entry actually fires; one with no notes, one with a track nothing points at, and an empty path all read |
| Version 1 | A synthetic path reads with its float count; a fractional, negative or absurd count is refused, and so is a file with anything after its entries |
| Malformed paths | A wrong identifier, both unsupported versions, negative and zero counts, entries past the end, a note range that leaves the track, an unterminated note and a track that does not end the file are all refused, as is every truncation |

Tests: `tests/jka_roff_tests.cpp` (`meson test fntech3_jka_roff`).

No retail path or asset is required, incorporated or shipped.
