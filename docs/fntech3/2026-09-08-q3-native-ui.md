# Exercise Q3 native UI alongside the legacy cgame fixture

The Q3 opt-in runner now builds a second test-only DLL, `uix86.dll`, and selects
both vm_cgame=0 and vm_ui=0 in the same isolated session. The UI fixture exports
legacy dllEntry/vmMain, reports API version 6, and uses public Q3 syscall ordinals
from the pinned GPL reference credited in CREDITS. It contains no menu or retail
game implementation.

The actual Windows x86 engine logs legacy vmMain loading for both modules. UI
checks cover API negotiation, guarded 0x2c44-byte glconfig transfer, a guarded
3,084-byte uiClientState transfer in CA_ACTIVE with a valid client number and
three bounded strings, a nonempty terminated server-info configstring, console
command dispatch and shutdown. The six earlier cgame transfer/callback checks
also pass. The engine unloads/reloads UI during startup and shuts it down again
on normal exit; those callbacks are visible in the evidence log.

The same FNTECH3_Q3_CGAME_RUNTIME_EXE opt-in variable now enables both Q3 client
fixtures. An optional FNTECH3_Q3_CGAME_PROBE_OUTPUT directory receives both DLL
and source hashes, commands, markers and exit state. Q3 retail assets and qagame
QVM remain read-only inputs; synthetic DLLs live only in the temporary home.
The private desktop is never switched, windowed GLx and disabled input are
forced, and the session exits normally through startup commands. No user input
is injected and no screen capture is used.

The full Windows suite with Q3 and QL native probes enabled passes 110 configured
checks, zero failures and one unavailable OpenAL skip; its aggregate passes
1,270 tests with five skips.

The [evidence record](2026-09-08-q3-native-ui.json) preserves the run. Pure is
disabled for these synthetic DLLs. This establishes bounded native UI/cgame ABI
coverage, not retail-peer interoperability, UI visual correctness or a complete
import audit. Q3 native qagame, QL unknown snapshot-tail meaning and broader
release/compatibility gates remain open. No new unrelated engine issue was found.
